One line, 67 characters, about office life — for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty, $2 in USDC.

`main.py` (Python 3.13, standard library only) writes a single original office joke: the boss calls the team a family, so the narrator asks HR for a weekly allowance. No network, no clock, no files outside the repository: two runs write the same bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`out/entry.txt` is the joke (67 characters, one line).
